# ClickHelp Documentation

> The official ClickHelp User Manual: content authoring, collaboration, publishing, localization, portal administration, integrations, APIs, and AI-assisted documentation features. Links point to the canonical Markdown version of each page.

Any page on this portal is available as Markdown by appending `.md` to its URL. The REST API is documented by the linked OpenAPI files rather than by per-endpoint pages.
